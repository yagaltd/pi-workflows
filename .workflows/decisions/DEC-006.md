# DEC-006: A shipped plan id without an archive dir is drift

> Status: active
> Decided-by: 20261117-064
> Scope: .workflows/archive/done, scripts/check-drift.sh, skills/ship
> Revisit when: SHIP writes the bundle itself instead of moving it by hand, or the drift rule proves too noisy to keep

Rule: Eight shipped plans (055, 056, 057, 058, 059, 060, 062, 063) left no archive bundle; the cause is that SHIP ran without the archive step, so the move stayed a manual action no gate checked — the gap, not the plans, is the defect. Henceforth a shipped plan id without an archive dir is drift: every `(plan <id>)` in the first 10 CHANGELOG entries must appear in a `.workflows/archive/{done,superseded}/*` dir name (enforced by plan 20261117-064 TASK 3), and those nine ids are back-filled by TASK 2 as reconstruction bundles whose original plan text is stated lost. Two cosmetics are accepted, not fixed: the agent-spec remote is named `fork`, and `target/` is symlinked into the mise cache. Recorded with this decision: `.workflows/decisions/` was itself git-ignored until 4c13428, so this ledger (DEC-001..005 + INDEX) had never been committed and would have been lost on a fresh clone.
